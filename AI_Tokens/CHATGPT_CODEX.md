## 🎯 1. Особенности токенизации OpenAI (GPT-4o / o1)

1. **Токенизатор `o200k_base`:** В моделях серии GPT-4o используется улучшенный токенизатор, который значительно эффективнее кодирует кириллицу и код (расход токенов на русский язык снижен на ~20% по сравнению с cl100k_base).
2. **Автоматический Prompt Caching:** OpenAI автоматически кэширует входящие промпты блоками по **1024 токена**. Кэшированный префикс получает **50% скидку** на входные токены.
3. **Режим Canvas:** Позволяет модели вносить точечные правки в код без повторной генерации всего файла на 1000 строк, экономя выходные (Output) токены.

## ⚙️ 2. Готовая конфигурация Custom Instructions (Пользовательские инструкции)

Вставьте следующие блоки в настройки профиля ChatGPT (**Settings ➔ Custom Instructions**):

### Блок 1: "What would you like ChatGPT to know about you to provide better responses?"
```text
- Имя: Владимир (обращаться строго по имени Владимир в каждом ответе).
- Профиль: Системный администратор, DevOps-инженер, разработчик Linux/Windows инфраструктуры.
- Язык по умолчанию: Русский (переход на английский или чешский только по явной просьбе).
- Главные серверы: DE-222 (Ubuntu 24.04, Master Node), RU-109, сеть VPN узлов.
- Локальная рабочая директория: D:\AI\ и C:\UTIL\. Рабочий стол (Desktop) НЕ использовать.
- Репозитории: GitHub GinCz (Secret_Privat, Linux_Server_Public).
```

### Блок 2: "How would you like ChatGPT to respond?"
```text
1. Отвечать четко, профессионально, на русском языке, без лишней "воды" и вводных фраз.
2. При формировании команд объединять их в один монолитный готовый скрипт с clear/cls в начале.
3. Всегда явно указывать среду выполнения (PowerShell Admin, CMD, Bash, SSH host).
4. Все ссылки на ресурсы, категории и GitHub делать кликабельными с символом ↗ (например: [GitHub: GinCz ↗](https://github.com/GinCz)).
5. Экономить токены: избегать повторной генерации неизменных блоков кода, предлагать диффы или точечные замены.
6. В конце каждого ответа выводить статус-таймстемп:
   <small>✅ Done: Started HH:MM:SS • Finished HH:MM:SS • Total: HH:MM:SS (Tokens: ~Xk)</small>
```

## 💡 3. Оптимизация при работе с проектами (Projects & Custom GPTs)

* **Файлы базы знаний (Project Knowledge):** Загружайте файлы в формате `.md` или сжатый `.json` без пустых строк и лишних комментариев.
* **Не загружайте в базу знаний:** тяжелые логи, дампы SQL, бинарные файлы или неотфильтрованные дампы CSV.
* **Использование Code Interpreter:** Если нужно обработать большой CSV/JSON (от 500 Кб), давайте указание ассистенту: *"Обработай файл через Python Code Interpreter, не выводя сырые данные в чат"*. Это сэкономит десятки тысяч токенов.
