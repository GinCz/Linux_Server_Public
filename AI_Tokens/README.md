## 🚨 Превентивный щит: Dual-Trigger Session Guard

AI-ассистент **ОБЯЗАН** выводить красное предупреждение в самом начале ответа при срабатывании **ЛЮБОГО** из двух триггеров:

1. 📊 **По объему контекста:** сессия приближается к **25k токенов** (или после 2+ тяжелых скриптов / дампов консоли).
2. 🔄 **По числу шагов:** сессия превысила **8–10 шагов** в режиме кодинга (или **12–15 шагов** в текстовом режиме).

```markdown
> <span style="color:#ff3333; font-weight:bold; font-size:1.1em;">⚠️ ВНИМАНИЕ: Контекст диалога перегружен (>25k токенов / >8 активных шагов)! Во избежание лавинообразного перерасхода токенов зафиксируйте изменения в Git (WORKLOG.md) и начните новый чат (Ctrl+N / Cmd+N)!</span>
```

> 💡 **Почему это критично в DevOps:** При каждом новом сообщении LLM повторно пересылает **всю историю чата**. Диалог на 25 сообщений сжигает в 10–15 раз больше токенов за один ответ, чем чистая сессия.

## ⚡ 10 Инженерных правил оптимизации токенов (DevOps Best Practices)

1. 🎯 **Принцип «Один чат — одна задача» (`Ctrl+N` / `Cmd+N`):**
   * Выполнил задачу или микроэтап ➔ зафиксировал изменения в Git ➔ открыл чистый чат. Экономит 90–95% токенов.
2. 📝 **Сквозной Git Worklog (`WORKLOG.md`):**
   * Все шаги, конфиги, решения и фиксы пиши в Markdown-журнал `WORKLOG.md`. Новый чат подхватывает контекст за 500 токенов вместо 50k токенов истории.
3. 📂 **Local-First доступ:**
   * Храни серверные карты, ключи и документацию локально на диске. Чтение локального файла — 100 токенов, парсинг веба — 15,000 токенов.
4. 👤 **Name Canary (Канарейка амнезии):**
   * Агент обращается строго по имени без пустых приветствий («Здравствуйте», «Привет»). Пропало имя — сигнал размытия внимания модели, пора жать `Ctrl+N`.
5. 🚫 **Zero-Bloat Chat (Запрет спама кодом в чат):**
   * Большие скрипты и Base64 пишутся напрямую в файлы (`write_to_file` в `C:\UTIL\` или `D:\AI\`). В чат — только краткий diff и путь.
6. ✂️ **Slice-Only Reading (Точечное чтение):**
   * Запрещено читать файлы целиком. Только окна строк (`StartLine`/`EndLine` по 50–100 строк) и целевой `grep_search` / `ripgrep`.
7. 📦 **Монолитные скрипты:**
   * Объединяй серии команд в один готовый монолитный блок/скрипт с очисткой консоли (`clear` / `cls`) в начале. Без интерактивного построчного спама.
8. ⏱️ **Anti-Hang & Anti-Polling:**
   * Запрещены polling-циклы ожидания в чате. Если задача длится > 2 минут ➔ переводи в фоновый демон/cron с алертом в Telegram.
9. 🛡️ **Строгие Ignore-фильтры:**
   * Исключай из контекста и индексации `.git/`, `node_modules/`, `vendor/`, `dist/`, `build/`, `*.log`, `*.zip` и бинарные дампы.
10. 🏢 **Corporate Data Masking (Confluence, Jira, Microsoft 365):**
    * Запрашивай только метаданные (`limit=3..5`, key, summary, status). Запрещен парсинг вложений и тредов на 50+ комментариев.
