# 🚀 Debian 12 (Bookworm) Slim & Fast Optimizer

Превратите чистый **Debian 12 (Bookworm)** в ультралегковесную, защищенную и производительную серверную систему (**~35–45 МБ RAM в простое**) всего за **10 секунд**.

Полная замена долгой и нестабильной установки DietPi без перепаковки стандартного окружения Debian.

---

## ⚡ Преимущества перед DietPi и Ubuntu 24

| Показатель | Ubuntu 24.04 Server | Debian 12 (Базовый) | **Debian 12 + Slim Optimizer** | DietPi |
|:---|:---:|:---:|:---:|:---:|
| **RAM в простое** | ~200–280 МБ | ~70–85 МБ | **~35–45 МБ** | ~35–50 МБ |
| **Занятый диск** | ~4.5–6 ГБ | ~1.3–1.6 ГБ | **~0.9–1.1 ГБ** | ~1.0–1.2 ГБ |
| **Время настройки**| ~2 мин | Мгновенно | **+ 10 секунд (1 команда)** | 20–35 минут |
| **Совместимость** | Высокая | 100% Эталонная | **100% Стандартный Debian** | Средняя (свои меню) |
| **TCP Стек** | Cubic | Cubic | **TCP BBR (Ускорение)** | Зависит от меню |

## 🚀 Быстрый запуск в 1 команду (SSH Root)

Выполните команду на только что установленном сервере с Debian 12:

```bash
clear; apt-get update -qq && apt-get install -y -qq curl ca-certificates && bash <(curl -fsSL https://raw.githubusercontent.com/GinCz/Linux_Server_Public/main/Debian12_Slim/debian12_slim.sh)
```

---

## 🛠️ Что делает оптимизатор:

1. **Оптимизация виртуальных консолей:** Отключает неиспользуемые `getty@tty2..tty6` (освобождает ~8-12 МБ RAM).
2. **Лимитирование логов journald:** Ограничивает журнал systemd до 30 МБ на диске и 15 МБ в памяти со сжатием логов (вместо неограниченного роста).
3. **Отключение лишних фоновых служб:** Отключает `multipathd`, таймеры проверки обновлений и motd-news.
4. **Тюнинг ядра и сети (Sysctl + TCP BBR):**
   * Включает алгоритм управления перегрузкой **TCP BBR** и планировщик `fq` (максимальная скорость сети и низкий пинг);
   * Оптимизирует `vm.swappiness = 10` и давление кэша файловой системы `vm.vfs_cache_pressure = 50`;
   * Увеличивает системные лимиты дескрипторов файлов (`fs.file-max = 2097152`).
5. **Генеральная очистка диска:** Очищает кэши APT (`autoremove --purge`, `clean`), вакуумирует старые системные логи и удаляет мусор из `/tmp/`.
6. **Диагностический отчёт:** Выводит актуальный статус ядра, TCP BBR, памяти (`free -h`), диска (`df -h /`) и нагрузки (`uptime`).
