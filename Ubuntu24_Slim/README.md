# 🚀 Ubuntu 24.04 LTS Hardcore Slim & Performance Optimizer

Глубокая оптимизация и безопасная очистка серверов под управлением **Ubuntu 24.04 LTS**.

Снижает потребление оперативной памяти со **~250–350 МБ до ~60–80 МБ**, удаляет фоновый мусор Canonical, освобождает гигабайты на диске и ускоряет сетевой стек (TCP BBR).

> 🛡️ **100% БЕЗОПАСНОСТЬ ДЛЯ СЕРВИСОВ:**  
> Скрипт специально спроектирован для рабочих серверов и VPN-узлов. Он **не затрагивает** и сохраняет работоспособность:
> * **Xray / 3x-ui** (VPN ядро и панель управления);
> * **Samba 4** (`smbd`, `nmbd`, права доступа и шары `/storage`);
> * **AdGuard Home** (DNS сервер и веб-интерфейс);
> * **Uptime Kuma** (мониторинг доступности);
> * **Docker**, **SSH** и правила **UFW**.

---

## 🚀 Быстрый запуск в 1 команду (SSH Root)

Выполните команду на сервере с Ubuntu 24.04:

```bash
clear; apt-get update -qq && apt-get install -y -qq curl ca-certificates && bash <(curl -fsSL https://raw.githubusercontent.com/GinCz/Linux_Server_Public/main/Ubuntu24_Slim/ubuntu24_slim.sh)
```

---

## 🛠️ Что конкретно делает скрипт:

1. **Защитный аудит:** Автоматически определяет запущенные рабочие сервисы (Xray, Samba, AdGuard, Uptime Kuma, Docker) и гарантирует их неприкосновенность.
2. **Удаление телеметрии Canonical:** Вычищает `apport`, `whoopsie`, `ubuntu-report`, `popularity-contest`, `landscape-common`.
3. **Очистка Snapd:** Если на сервере нет пользовательских snap-пакетов, безопасно удаляет snapd и блокирует его повторную установку (освобождает **150–200 МБ RAM** и ~1–2 ГБ диска).
4. **Отключение балласта:** Деактивирует `multipathd`, `udisks2`, `cloud-init` (после первого старта), `apt-daily.timer`, `motd-news.timer` и `getty@tty2..tty6`.
5. **Лимит журнала:** Устанавливает жесткий лимит логов `systemd-journald` в 30 МБ на диске со сжатием (вместо гигабайтов).
6. **Сетевой и ядерный тюнинг (TCP BBR):**
   * Включает скоростной алгоритм перегрузки **TCP BBR** и планировщик `fq` (увеличивает пропускную способность VPN и Samba, снижает задержки);
   * Устанавливает `swappiness = 10` и `vfs_cache_pressure = 50`;
   * Увеличивает лимит дескрипторов файлов (`fs.file-max = 2097152`) и сетевую очередь (`somaxconn = 65535`).
7. **Генеральная зачистка:** Удаляет остатки удаленных пакетов, очищает кэши APT, `/var/crash/`, `/tmp/`.
8. **Проверка работоспособности:** Тестирует и выводит живой статус всех ключевых служб (Xray, Samba, AdGuard, Uptime Kuma, SSH, UFW).
