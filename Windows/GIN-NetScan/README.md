# 🌐 GIN-NetScan (v035)
> **Ultra-Fast Multi-Subnet Hardware Network Discovery, Latency Profiler & Service Auditor for Windows 10/11**
> *Developed by VladiMIR+AI (Vladimir Bulantsev — GinCz)*

---

## 🚀 Key Features

* **⚡ Ultra-Fast Parallel Hardware Discovery:** Probes entire IPv4 subnets (`/24`, `/16`) in seconds using asynchronous ARP hardware table inspection and ICMP ping probes.
* **🌈 Color-Coded Categorization:** Distinctive vibrant colors and full-color emojis for device classes:
  * 👑 🌐 **Gateway / Router** — Royal Indigo / Purple
  * 📱 🍎 **Apple Devices (iPhone / iPad / Mac)** — Apple Sky Blue
  * 📱 📲 **Smartphones & Android** — Vibrant Emerald Green
  * 💻 🖥️ **PC / Workstations** — Windows Fluent Blue
  * ⚡ 💡 **Smart IoT Nodes & Sensors** — Warm Amber Gold
  * 📡 📶 **Access Points & Mesh Nodes** — Cyan / Teal
  * 📹 📷 **IP Surveillance Cameras** — Radiant Coral Red
  * 📺 🎬 **Smart TVs & Media Players** — Vibrant Magenta / Violet
  * 🖨️ 📄 **Network Printers** — Bronze / Amber
  * 💻 🗄️ **NAS Servers & Storage** — Deep Navy
  * 👻 🕵️ **Ghost Nodes (Stealth / Unknown OUI)** — Slate Gray
* **🎨 Color-Coded Ping Latency (RTT):**
  * `< 5 ms`: Emerald Green (Ultra-fast LAN)
  * `< 30 ms`: Fluent Blue (Good connection)
  * `≥ 30 ms`: Orange (High latency)
* **💾 Save Log:** 1-Click export of the network inventory table directly to Desktop in UTF-8 formatted text report.
* **🔍 Full 36-Port Service Auditor:** Deep port scan for HTTP, HTTPS, SSH, RDP, SMB, RTSP, DNS, SNMP, MQTT, etc., with dedicated multi-threaded audit window (on-demand manual port audit via right-click).
* **📦 2-in-1 Portable + Permanent Installer:**
  * Runs instantly with zero dependencies.
  * Bottom dynamic action button:
    * **`Install` (Red):** Installs cleanly to `C:\Program Files\GIN-NetScan`, creates Desktop and Start Menu shortcuts, and registers in Windows Programs and Features.
    * **`v035 Installed` (Green):** When already installed.
    * **`⚡ Обновить` (Amber Gold):** Dynamic 1-click update when a new version is released.
