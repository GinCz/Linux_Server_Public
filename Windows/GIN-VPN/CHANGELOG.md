<br>

* **Ключевые изменения:**
  - **🛡️ Глубокая очистка системного прокси при отключении на Windows 7 / 8 / 10 / 11:**
    - Устранена критическая проблема на Windows 7, когда после нажатия «Отключить» или «Выход» пропадал интернет с ошибками `ERR_SSL_PROTOCOL_ERROR` («Сайт не поддерживает защищенное подключение») или `ERR_PROXY_CONNECTION_FAILED`.
    - Функция `setWindowsProxy(false, "")` теперь детерминированно выполняет полный цикл очистки:

      4. Полностью очищает бинарные блобы конфигураций подключений (`reg delete ...\Connections /va /f`), включая `DefaultConnectionSettings` и `SavedLegacySettings`.
      5. Вызывает `netsh winhttp reset proxy` для сброса общесистемных сетевых служб.
      6. Уведомляет систему через `InternetSetOptionW` (`INTERNET_OPTION_SETTINGS_CHANGED` и `INTERNET_OPTION_REFRESH`).
  - **🚀 Мгновенная самоочистка в установщиках (`GIN-VPN_Installer.exe`, `.cmd`):**
    - Установщик перед запуском и развертыванием теперь автоматически выполняет глубокую очистку зависших прокси-настроек, моментально возвращая ПК в чистое рабочее состояние.

    - Автоматический перебор серверов при сбое подключения теперь изолирован **строго внутри выбранной подписки** (`p.Subscription == targetSub`).

    - Как только какому-либо серверу из подписки удается успешно подключиться, он **автоматически назначается сервером по умолчанию (`Default = "✔"`)**.
    - В таблице в колонке «Auto» мгновенно появляется галочка `✔`, настройки сохраняются в локальное хранилище, и при последующих запусках программы GIN-VPN будет сразу подключаться именно к этому проверенному рабочему серверу.
