## 🎯 What's New in v028
* **Streamlined Context Menu Hierarchy:** Re-engineered the System Tray right-click context menu into a clean, intuitive structure:
  1. 🎙️ Start/Stop Dictation with hotkey;
  2. ⚙️ Settings / API Key Setup;
  3. 🖥️ Interface Language Submenu;
  4. 🌐 Speech Recognition Languages Submenu;
  5. 🚀 Windows Autostart Toggle;
  6. 📋 Keep Recognized Text in Clipboard Toggle;
  7. ⌨️ Auto-Paste Text at Cursor Toggle;
  8. 📖 Interactive HTML Guide & Help;
  9. ✨ Check for Updates;
  10. ❌ Exit.
* **Eliminated Redundant Menu Items:** Removed secondary options ("Open Dictionary" and "Link Knowledge Folder") from the primary tray menu, keeping them accessible in the Settings window.
* **Guaranteed Embedded PE Installer Icon:** Continuous validation of multi-resolution embedded PE icon resources (`.rsrc`).
