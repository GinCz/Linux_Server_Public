🎙️ GIN-Voice [v029]

Ultra-Fast Voice Typing & AI Dictation with Whisper Large v3 for Windows 10/11

1
Get your Free Groq Whisper API Key

GIN-Voice utilizes the high-speed Groq Whisper AI engine to achieve instant speech-to-text recognition in ~0.3 seconds. It is completely free (providing up to 7,000 seconds of audio dictation every single day at no cost).

🌐 Open Groq API Keys Console ↗
  • Sign in with your Google or GitHub account;
  • Click the blue «Create API Key» button;
  • Copy your generated secret key (starts with gsk_...).
2
Enter Key & Save Settings

Paste your key into the GIN-Voice Control Center dialog and click «💾 Save & Apply».

  • You will see a confirmation dialog and a soft chime confirming activation.
  • GIN-Voice minimizes directly to the Windows System Tray (near the taskbar clock).
  • To open settings anytime, right-click the tray microphone icon → Settings & Control Center.
3
How to Use (1-Key Global Hotkey)
  • Place your cursor anywhere (Browser, IDE, Chat, Telegram, Word, Terminal).
  • Press F4 (or click [ Record ] in settings to bind any custom hotkey) — a gentle chime sounds and the top HUD glows cyan.
  • Speak naturally in English, Russian, Czech, or any of the 18 supported languages.
  • Press F4 again — your speech is instantly transcribed and typed directly at your cursor!
🎨
HUD Customization & Aesthetic Fonts

The top HUD overlay features sleek, modern typography. In the settings dialog, you can choose your favorite font:

  • Comfortaa (Default) — Clean, soft, rounded aesthetic for a futuristic look.
  • Segoe UI / Segoe UI Variable — Native Windows 11 fluent typography.
  • Bahnschrift / Montserrat / Consolas — Bold cyber and developer styles.
★
Multi-Language & Smart Auto-Dictionary
  • Simultaneous Multi-Language Speech: Check multiple languages (e.g. English + Russian + Czech) for seamless multilingual conversations without switching.
  • Canonical Project Auto-Correction: Mentions of projects like GIN-TV, GIN-Cinema, GIN-NetScan, GIN-Voice, Secret_Privat, ORACLE_157 are automatically capitalized correctly.
  • Knowledge Base Linking: Link any project folder in settings to automatically index project terms and names into the voice dictionary.
  • Autostart: Enable Autostart on Windows Boot to always have GIN-Voice ready at your fingertips.

🎙️ GIN-Voice [v029]

Мгновенный голосовой ввод и диктовка нейросетью Whisper Large v3 для Windows 10/11

1
Получите бесплатный ключ Groq API

Для сверхбыстрого распознавания речи за ~0.3 секунды программа использует движок Groq Whisper AI. Он полностью бесплатен (дает до 7 000 секунд голосового ввода в день бесплатно).

🌐 Открыть страницу ключей Groq API ↗
  • Войдите через аккаунт Google или GitHub;
  • Нажмите синюю кнопку «Create API Key»;
  • Скопируйте сгенерированный ключ (начинается на gsk_...).
2
Вставьте ключ и сохраните настройки

Вставьте скопированный ключ в появившееся окно Центра Управления GIN-Voice и нажмите «💾 Сохранить и Применить».

  • Программа выведет окно подтверждения и приятный звуковой сигнал активации.
  • GIN-Voice сворачивается в системный трей Windows (рядом с часами).
  • Чтобы открыть настройки в любой момент: правый клик по значку микрофона в трее → Центр Управления.
3
Как пользоваться (управление одной комбинацией)
  • Поставьте курсор в любое место (браузер, блокнот, чат, Antigravity, Telegram, Word).
  • Нажмите F4 (или нажмите [ Запись ] в настройках и нажмите любую удобную вам клавишу) — прозвучит мягкий сигнал, сверху появится аккуратная кибер-плашка HUD.
  • Продиктуйте нужный текст на русском, английском, чешском или любом из 18 языков.
  • Нажмите F4 повторно — нейросеть мгновенно напечатает текст прямо у вашего курсора!
🎨
Выбор красивого шрифта для верхней плашки (HUD)

Верхняя статусная строка выполнена в элегантном нежирном стиле. В окне настроек можно выбрать подходящий шрифт:

  • Comfortaa (По умолчанию) — Стильный округлый футуристический шрифт без жирного начертания.
  • Segoe UI / Segoe UI Variable — Фирменный плавный интерфейсный шрифт Windows 11.
  • Bahnschrift / Montserrat / Consolas — Четкие геометрические и моноширинные варианты.
★
Мультиязычность и умный словарь автозамен
  • Одновременная речь на разных языках: Отметьте нужные языки (например, Russian + English + Czech) для свободного смешанного голосового ввода.
  • Автоисправление названий проектов: Произнесенные названия автоматически пишутся в каноническом виде: GIN-TV, GIN-Cinema, GIN-NetScan, GIN-Voice, Secret_Privat, ORACLE_157.
  • Привязка папки знаний: Привяжите общую папку с базами знаний для автоматического добавления терминов и имен в словарь.
  • Автозапуск: Отметьте пункт Автозапуск при старте Windows в трее, чтобы диктовка всегда была под рукой.
