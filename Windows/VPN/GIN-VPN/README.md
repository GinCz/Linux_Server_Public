## 🌟 Основные возможности
1. **Нативный высокоскоростной Xray Core VLESS-Reality Client** без громоздких надстроек и Electron.
2. **Полупрозрачный 3D Glassmorphism UI:** элегантный дизайн с объёмными кнопками, пастельными тонами и защитой от обрезки текста на любых масштабах экрана (DPI scaling).
3. **Умное состояние установки и обновления:**
   - **Портативный режим:** кнопка `[ 📑 Install App ]` и предупреждающий баннер.
   - **Установленная актуальная версия:** кнопка `[ 🟢 Last Version v24 ]` и зелёный статус.
   - **Обнаружение новой версии:** яркая кнопка `[ ⚡ Update: v24 ➔ v25 ]` с бесшовным апгрейдом в один клик.
4. **Официальный деинсталлятор в Windows:**
   - Регистрация в списке «Программы и компоненты» Windows (`HKLM`/`HKCU` `Uninstall`).
   - Автоматическое корректное удаление ярлыков, реестра, сброс прокси WinINet и очистка файлов.
5. **Диагностика в реальном времени:**
   - Мониторинг оригинального IP (`Original ISP IP`) и защищённого IP (`Protected VPN IP`).
   - Измерение RTT-задержки (Latency) и таймер активной сессии (`Session Uptime`).

## 📂 Состав пакета
- `GIN-VPN.ps1` — основной PowerShell Windows Forms клиент.
- `GIN-VPN.bat` — автоповышающий права Batch-запускатель.
- `Uninstall.ps1` / `Uninstall.cmd` — официальный деинсталлятор для Windows.
- `config.json` — автоматически генерируемая конфигурация Xray.
- `vpn.log` — журнал событий трафика и маршрутизации.
