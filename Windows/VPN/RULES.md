## 🚫 1. ЗАПРЕТ МУСОРА НА РАБОЧЕМ СТОЛЕ
1. **Категорический запрет на любые сторонние файлы:**
   - **ЗАПРЕЩЕНО** выгружать на Рабочий стол иконки (`.ico`), конфигурации (`.json`, `.txt`, `.cfg`), логи, ярлыки (`.lnk`) или батники (`.bat`/`.cmd`).
   - Иконка программы **ВСЕГДА вшивается внутрь `.exe` файла** на этапе компиляции через `rsrc`.
2. **Только ЕДИНСТВЕННЫЙ `.exe` файл актуальной версии:**
   - На Рабочем столе для каждого инструмента (`GIN-VPN`, `GIN-NetScan`) должен находиться **ТОЛЬКО ОДИН файл `.exe`** с номером текущей версии в названии (например, `GIN-VPN_v013.exe`, `GIN-NetScan_v025.exe`).
   - Этот файл является полноценной portable-версией, содержащей внутри кнопку `[ Install App ]` для инсталляции на текущую машину при необходимости.
3. **Очистка старых версий:**
   - При сборке новой версии (например, `v014`) старая версия (`v013`) **НЕМЕДЛЕННО удаляется** с Рабочего стола через `mega-rm`.

---

## 📂 2. ХРАНЕНИЕ ВСЕХ ИСХОДНИКОВ, ИКОНОК И КОНФИГУРАЦИЙ
- Все исходные коды (`main.go`, `.ps1`), иконки (`.ico`), `.syso`, манифесты и конфигурации хранятся **ТОЛЬКО в приватном репозитории GitHub в папке `Windows/` (`Windows_Scripts/`)**, каждое приложение строго в своей отдельной подпапке:
  - `Windows/GIN-VPN/` (`main.go`, `Gin-VPN.ico`, `rsrc_windows_amd64.syso`, `GIN-VPN_v0XX.exe`, `Uninstall.cmd`, `README.md`)
  - `Windows/GIN-NetScan/` (`main.go`, `Gin-NetScan.ico`, `rsrc_windows_amd64.syso`, `GIN-NetScan_v0XX.exe`, `README.md`)

## ⚡ 3. КОМАНДЫ ДЕПЛОЯ НА РАБОЧИЙ СТОЛ (MEGA)
```bash
# 1. Удаление старой версии с Рабочего стола
mega-rm "/MEGA/DOCS/desktop/<Старое_Имя_vXXX>.exe" 2>/dev/null || true

# 2. Загрузка строго ЕДИНСТВЕННОГО нового .exe файла со вшитой иконкой
mega-put -c "<путь_к_новому_билду.exe>" "/MEGA/DOCS/desktop/"
```
