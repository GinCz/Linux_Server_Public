### 📋 Description
Ultra-lightweight SEO-compliant 404 handler for WordPress by **VladiMIR+AI**.

- **For Search Engines (Yandex, Google, Bing, Seznam):** Immediately returns authentic `HTTP/1.1 404 Not Found` response header with `noindex, nofollow` metadata. Ensures search bots instantly drop dead/broken links from the index, eliminating "Soft 404" errors and saving crawl budget.
- **For Human Visitors:** Displays a sleek, modern responsive card with a **live 5-second countdown timer** and smooth automatic redirection to the homepage. Visitors can click the direct button or cancel the timer if desired.

### 🚀 Installation
1. Download archive `404-410-301-(VladiMIR+AI).zip`.
2. In WordPress Admin, navigate to **Plugins ➔ Add New ➔ Upload Plugin**.
3. Choose `404-410-301-(VladiMIR+AI).zip` and click **Install Now**.
4. Click **Activate Plugin**.
