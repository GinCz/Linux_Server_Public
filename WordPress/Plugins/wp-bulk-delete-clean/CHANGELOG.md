# Changelog - WP Bulk Delete Clean

## [2026-09__1.31] - 2026-09-20
### Added
- Initial release of WP Bulk Delete Clean (VladiMIR+AI✅).
- Ad-free, lightweight alternative to commercial bulk deletion plugins.
- AJAX batch deletion with zero server timeout risk and zero memory bloat.
- Comprehensive date filters (before, after, date range, older/newer than X days, published vs modified date).
- Post type filters for Posts, Pages, WooCommerce Products, and Custom Post Types.
- Taxonomy filters for Categories, Tags, and Custom Taxonomies.
- Permanent delete vs Move to trash modes.
- Cleanup of associated media/images.
- Live progress bar, preview count, pause/resume/stop controls, and activity log.
- Shared VladiMIR+AI updater and 8-language i18n support.
