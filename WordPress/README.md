## 🛠️ Способы установки

### Вариант А: Стандартная установка через консоль WordPress
1. Перейдите в папку нужного плагина выше и скачайте соответствующий `.zip` файл.
2. В админке WordPress откройте: **Плагины ➔ Добавить новый ➔ Загрузить плагин**.
3. Выберите `.zip` архив и нажмите **«Установить»**, затем **«Активировать»**.

### Вариант Б: Установка через Must-Use (Автономный режим)
Скопируйте нужный `.php` файл напрямую в папку `/wp-content/mu-plugins/` на сервере. Плагин активируется автоматически и не будет отображаться в общем списке обычных плагинов.
