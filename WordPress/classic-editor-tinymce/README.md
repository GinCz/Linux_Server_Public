### 📋 Description
All-in-one classic visual editing suite for WordPress by **VladiMIR+AI**.

- **Disables Gutenberg:** Turns off the Gutenberg block editor for posts, pages, and custom post types, restoring the traditional editor with "Visual" and "Text (HTML code)" tabs.
- **Disables Block Widgets:** Restores the traditional, responsive widget administration screen.
- **Dequeues Block CSS:** Prevents `wp-block-library.css` and block global styles from loading on the frontend, boosting page load speeds.
- **Word-Like Formatting Toolbar:** Keeps the 2nd toolbar row open by default, featuring Microsoft Word-like formatting controls:
  - Format selector (Paragraph / Headings)
  - Font size selector dropdown (clean, deduplicated)
  - Text color & background marker highlight color (deduplicated)
  - Insert and manage HTML tables
  - Paste as plain text (strips unwanted styling from Word or external websites)
  - Clear formatting (eraser)
  - Special characters (charmap / omega)
  - Subscript & superscript (x² / H₂O)
  - Indent & outdent
  - Undo & redo
  - Cleaned toolbar with keyboard shortcuts button removed for a clutter-free experience.
