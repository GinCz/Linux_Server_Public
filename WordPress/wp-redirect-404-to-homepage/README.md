# 301 Redirect 404 to Homepage (VladiMIR+AI)

An ultra-lightweight WordPress micro-plugin to automatically 301-redirect all `404 Not Found` error pages directly to the homepage (`/`).

---

## ⚡ Features

- **Direct 301 Permanent Redirect:** Sends visitors instantly to the homepage on any missing URL.
- **Zero Database Queries:** Does not create or poll any database tables.
- **Zero Log Bloat:** Does not record 404 hits in MySQL or file logs.
- **Sub-millisecond Execution:** Average execution time < 0.2 ms.

---

## 📦 Installation

1. Copy the `wp-redirect-404-to-homepage` directory to `wp-content/plugins/`.
2. Activate the plugin in **Plugins**.
