# wp-seo-micro

Minimal WordPress SEO: custom title, meta description, Open Graph tags, canonical URL, robots meta, XML sitemap. No bloated UI — just clean, fast SEO.

## Installation

1. Download or clone this repository
2. Upload the `wp-seo-micro` folder to `/wp-content/plugins/`
3. Activate through WordPress admin panel

## Requirements

- WordPress 6.0+
- PHP 8.0+
