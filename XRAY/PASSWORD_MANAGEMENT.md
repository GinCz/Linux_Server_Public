# Инструкция: Смена логина и пароля администратора в 3X-UI

> **Компонент:** 3X-UI (MHSanaei fork)  
> **Дата обновления:** 2026-09-23  
> **Применимость:** Все узлы VPN (DE-222, RU-109, Alex-39, 4er-108, TATRA_9, 4TON_237, STOLB_24, SHAHIN_227, SO_38, AWS-12)

---

## 1. Важная особенность безопасности (Bcrypt)

Панель **3X-UI** (начиная с версий 2.x/3.x) сохраняет пароли пользователей в базе SQLite `/etc/x-ui/x-ui.db` в виде **bcrypt-хэша** (`$2a$10$...`).

⚠️ **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:**
Записывать пароль в открытом виде прямым SQL-запросом:
```sql
-- НЕ ДЕЛАТЬ ТАК! Веб-интерфейс не примет пароль и выдаст "Неверные данные":
UPDATE users SET password='MyPassword' WHERE id=1;
```

---

## 2. Способ №1: Командная строка CLI (Быстро / Скрипты)

Вызов встроенного бинарного модуля 3X-UI, который автоматически рассчитывает соль и bcrypt-хэш:

```bash
# Одной командой задать логин и пароль:
/usr/local/x-ui/x-ui setting -username "<USERNAME>" -password "<PASSWORD>"

# Перезапустить сервис x-ui для применения сессий:
systemctl restart x-ui

# Проверить результат в базе данных SQLite:
sqlite3 /etc/x-ui/x-ui.db "SELECT id, username, password FROM users;"
```

*Пример корректной записи в БД:*
```text
1|vlad|$2a$10$EP1eiGiBQ/ThuFP.2w.23OqiLoGGCJvfx/qveaW1JeaFe6wiNLkbq
```

## 3. Способ №2: Интерактивное меню `x-ui`

1. Подключиться по SSH к нужному серверу.
2. Ввести команду:
   ```bash
   x-ui
   ```
3. В появившемся меню выбрать пункт **`7`** (`Reset Username & Password`).
4. Ввести новое имя пользователя (или нажать Enter для генерации).
5. Ввести новый пароль.
6. Подтвердить сброс двухфакторной аутентификации (если требуется).
7. Подтвердить перезапуск панели (`y`).

## 4. Способ №3: Массовая смена с Master Node (DE-222)

Для обновления учетных данных на удаленном узле через `DE-222`:

```bash
ssh -o BatchMode=yes -o ConnectTimeout=5 root@<IP_АДРЕС> "
  /usr/local/x-ui/x-ui setting -username 'vlad' -password 'Gin-79513'
  systemctl restart x-ui
"
```
