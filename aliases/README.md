# Master Shell Aliases & Modded Midnight Commander (`aliases`)

> Repository: [GinCz/Linux_Server_Public](https://github.com/GinCz/Linux_Server_Public)  
> Author: [Vladimir Bulantsev (@GinCz)](https://github.com/GinCz)  
> Directory: `aliases/`

Curated terminal productivity aliases, colored interactive prompts, SSH host shortcuts, and custom Midnight Commander (`mc`) configuration profiles.

---

## ⚡ Overview & Features

* **Terminal Productivity:** Shortened mnemonics for system diagnostics (`cleanup`, `servers_stat`, `sos`, `antivir`, `infooo`).
* **Custom Midnight Commander Skin:** High-contrast color palette, modern keybindings, and extended file associations.
* **Idempotent Deployment (`setup_aliases_modded_mc.sh`):** Appends to `~/.bashrc` safely without duplicate blocks.

---

## 🚀 1-Click Setup

```bash
bash setup_aliases_modded_mc.sh
source ~/.bashrc
```
