## 🚀 3. Преимущества и сценарии использования локальной сети

1. **Безлимитный межсерверный трафик 0 ₽:**
   - Передача данных между нодами (бэкапы, репликация Samba, зеркалирование баз данных x-ui.db) не расходует квоту тарифного пакета (1 ТБ/мес).
2. **Низкие задержки (Ultra-low latency):**
   - Прямой линк внутри одного дата-центра (RTT < 0.3-0.8 ms).
3. **Безопасность и изоляция:**
   - Внутренние управляющие порты (репликация, внутренний мониторинг, failover-кластеры) могут слушать исключительно локальный IP `10.x.x.x`, будучи недоступными из внешней сети Интернет.
4. **Отказоустойчивость и мониторинг (Uptime Kuma):**
   - Мониторинг на TATRA_9 может опрашивать ноды по внутренним адресам `10.15.x.x` независимо от блокировок внешних маршрутов.

## 🛠 4. Настройка сетевого интерфейса в Linux (Debian 12 / systemd-networkd / interfaces)

При подключении локальной сети в панели VDSina, операционная система получает второй сетевой интерфейс (обычно `eth1` или `ens7`/`enp0s7`).

### Проверка наличия интерфейса:
```bash
ip link show
ip addr show
```

### Настройка через `/etc/network/interfaces` (при ручной конфигурации):
```text
auto eth1
iface eth1 inet static
    address 10.15.1.203/16
    # Шлюз не указывается, чтобы не нарушать маршрут по умолчанию через eth0
```
