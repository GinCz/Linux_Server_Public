# Hardware Profiler & System Telemetry (`info`)

> Repository: [GinCz/Linux_Server_Public](https://github.com/GinCz/Linux_Server_Public)  
> Author: [Vladimir Bulantsev (@GinCz)](https://github.com/GinCz)  
> Directory: `info/`

Fast, comprehensive hardware spec aggregator and runtime telemetry profiler for Linux bare-metal and cloud servers (`infooo`).

---

## ⚡ Overview

`infooo.sh` aggregates critical server parameters into a clean, colored terminal summary:
* **Hardware Specs:** CPU model, physical/virtual cores, clock frequency, thermal sensor readings.
* **Memory & Storage:** Physical RAM vs swap allocation, NVMe/SSD partition layout, disk health.
* **Network & Routing:** Public IPv4/IPv6, default gateway, active network interfaces, DNS nameservers.
* **Kernel & OS:** Distribution release, kernel version, system uptime, and virtualization type.

---

## 🚀 Execution

```bash
bash infooo.sh
```
